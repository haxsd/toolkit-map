toolkit-map v1.1.2

这是隐藏后台子进程窗口的补丁版本，不改变扫描、选择、安装或 MCP 契约。

下载 `toolkit-map-v1.1.2-runtime.zip` 即可运行（含 scripts、MCP、schema 与文档；不含顶层 `tests/` 与 CI）。
SHA256 见同名 `.sha256` 文件；需要浏览完整源码时使用本页下方的 `Source code (zip)`。
安装与接入见 README，兼容承诺见 `docs/contract.md`。

本版修复：

- MCP 调用 `map.ps1` 时，PowerShell 子进程使用 `-WindowStyle Hidden` 与 `windowsHide`；
- 版本探测与超时清理的 `cmd.exe` / `taskkill` 使用隐藏窗口；
- `quickstart`、`demo`、`build-release` 启动的子 PowerShell 使用隐藏窗口。
