toolkit-map v2.0.0

## 兼容性变更

- `find` 严格只读，不再执行新候选、重新探测变化的文件或保存地图。只选用仍可访问且文件指纹未变的已验证候选；`-AllowUnverified` 不再受支持。
- 新候选需要用户明确授权后，通过 `scan`、`update` 或 `add` 验证。无匹配副本时不会回退到错误版本；只读搜索的范围有限，不能据此断言整台机器没有该工具。

## 地图维护与首次接入

- MCP 新增 `toolkit_scan`、`toolkit_update` 和 `toolkit_add`：默认预览，显示可确定的地图目标，确认时固定该目标；目标无法确定或存在路径歧义时拒绝执行。`confirm:true` 只是执行请求，客户端仍须取得用户明确授权。维护时可能执行候选程序取版本，不自动安装工具或修改 PATH。
- 地图文件不得使用 `.md` 扩展名；相邻 Markdown 文件只有在内容与上一张地图生成的摘要完全一致时才会更新，否则保留并返回告警。
- 手工登记的离线路径、备注和偏好会在重新扫描或更新时保留；重新登记同一路径且未填写新备注时保留已有备注。
- 接入程序在写入客户端配置前检查生成结果与服务启动；项目配置固定本次使用的地图，失败时明确报告部分完成。
- 修复版本声明、工具发现与扫描诊断问题，扩充隔离测试和发布包检查。地图与 JSON 结果继续使用 schema v2。

下载 `toolkit-map-v2.0.0-runtime.zip` 即可运行；SHA256 见同名 `.sha256` 文件。完整源码可从本页面的 Source code 下载；安装与接入见 README，兼容承诺见 `docs/contract.md`。
