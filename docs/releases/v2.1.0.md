toolkit-map v2.1.0

## 新功能

- **agent 自动维护地图**：`find` 新增 `maintenance`，返回地图年龄、待验证或变化的候选、`required` / `recommended`、建议动作和 `autoAllowed`。`find` 仍然只读，不执行候选、不写地图。
- **一次授权，定向维护**：`setup` 写入 `settings.maintenance`，默认预授权定向 `update <tool>`；未执行 `setup` 不预授权，`-NoAutoUpdate` 可关闭。`scan` / `add` / `install` 仍需用户确认，`install` 不会自动执行。
- **规则与 MCP 同步**：agent 规则、`SKILL.md`、`templates/*` 和 MCP 说明加入维护循环；`toolkit_update` 在 `find.maintenance.autoAllowed` 为 true 时可传 `confirm:true` 执行，然后重试 `find`。
- **维护待办更准确**：地图过期不再导致每次全量 `scan`；IDE / 编辑器宿主运行时默认不参选，也不会触发维护待办。原计划在 v2.0.1 的宿主运行时修复并入本版本。

## 升级

已有地图在升级后默认不预授权。在需要自动维护的项目里重新执行一次：

```powershell
.\scripts\map.ps1 setup -Project <项目目录> -Json
```

这会写入新的规则块并把共享地图的 `autoUpdate` 设为 true；不想自动定向更新时使用 `-NoAutoUpdate`。MCP 客户端需要重启以加载新的工具说明和 schema。

## 兼容性

- 地图与 JSON 结果仍使用 schema v2；新增 `settings.maintenance` 与 `maintenance` 均为可选字段，向后兼容。
- `find` 的只读承诺不变：不执行新候选、不写地图；只有 `update` / `scan` / `add` / `install` 会改变本机状态。
- 版本号提升到 2.1.0；安装与接入方式不变。

下载 `toolkit-map-v2.1.0-runtime.zip` 即可运行；SHA256 见同名 `.sha256` 文件。完整源码可从本页面的 Source code 下载；安装与接入见 [README](../../README.md)，兼容承诺见 [契约文档](../contract.md)。
