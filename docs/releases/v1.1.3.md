toolkit-map v1.1.3

这是消除后台命令窗口闪烁的补丁版本，不改变扫描、选择、安装或 MCP 契约。

下载 `toolkit-map-v1.1.3-runtime.zip` 即可运行（含 scripts、MCP、schema 与文档；不含顶层 `tests/` 与 CI）。
SHA256 见同名 `.sha256` 文件；需要浏览完整源码时使用本页下方的 `Source code (zip)`。
安装与接入见 README，兼容承诺见 `docs/contract.md`。

本版修复：

- MCP 子 PowerShell 继承 server 已有的隐藏控制台，不再每次调用新建 `conhost.exe`；
- 版本探测与超时清理继承当前 PowerShell 控制台，不再为每次探测新建隐藏控制台；
- `quickstart`、`demo`、`build-release` 不再强制隐藏子宿主，沿用调用者已有的控制台。
